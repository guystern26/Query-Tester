Splunk Custom Command

| aiguy

AI-powered analysis, enrichment, and extraction — right inside your SPL pipeline. Ask questions, classify data, extract fields, and get suggestions.

# Basic question
... | aiguy prompt="which host is busiest?"

# Preset mode
... | aiguy mode="anomaly"

# Enrich each row
... | aiguy mode="enrich" field="message" prompt="classify as critical, warning, or info"

# Extract a value
... | aiguy mode="extract" field="email" prompt="extract the domain" new_field_name="domain"
Modes
summary
Key findings and takeaways from the results.
anomaly
Outliers, unusual patterns, things that stand out.
trend
Time-based patterns — increasing, decreasing, stable.
alert
Should an alert fire? Yes/no with reasoning.
health
Overall system health assessment.
compare
Differences between groups in the data.
enrich
Per-row AI labeling — classify, categorize, explain each value.
extract
AI generates regex to extract values from a field. Falls back to dict mapping.
explain
Plain English explanation of the SPL query itself.
suggest
Suggests one follow-up SPL query to dig deeper.
dashboard
Fetches all panels from a dashboard and summarizes the overall situation.
top
Top items and why they're significant.
Options
ParameterRequiredDescription
prompt=if mode setYour question or instruction for the AI.
mode=if prompt setPreset analysis mode (see above).
field=enrich/extractWhich field to analyze, classify, or extract from.
value=optionalFilter: only rows where field=value are sent to AI.
new_field_name=optionalName for the new field (extract/enrich). Default: ai_answer.
Output Fields
ai_answer
The AI's response or extracted/enriched value
aiguy_timestamp
When the AI processed this row
aiguy_source
Source: live, regex, dict, partial, error
Examples
Ask a question
index=main | stats count by sourcetype | aiguy prompt="which sourcetype generates the most noise?"
Classify errors
index=_internal log_level=ERROR | dedup message | head 25 | aiguy mode="enrich" field="message" prompt="explain each error and how to fix it"
Extract a field
... | aiguy mode="extract" field="user" prompt="extract the domain from the email" new_field_name="domain"
Explain a complex query
index=firewall action=blocked | stats count by src_ip | sort -count | head 10 | aiguy mode="explain"
Dashboard summary
| makeresults | aiguy mode="dashboard" prompt="search/monitoring: any issues I should know about?"
Chain with Splunk commands
index=web status>=400 | stats count by uri | aiguy mode="enrich" field="uri" prompt="classify as API, static asset, or page" new_field_name="category" | stats sum(count) by category
25s deadline — returns partial results Persistent HTTPS connection Smart sampling — 20 unique rows from 10k Dynamic cell length for tracebacks Scheduled search rate limiting Works for all users
Quick Reference
# Analysis (one answer for all rows)
... | aiguy prompt="your question"
... | aiguy mode="summary|anomaly|trend|compare|alert|health|top"
... | aiguy mode="summary" field="host" value="web01"

# Per-row enrichment (AI labels each unique value)
... | aiguy mode="enrich" field="field_name" prompt="instruction"
... | aiguy mode="enrich" field="msg" prompt="explain" new_field_name="explanation"

# Field extraction (AI generates regex, fallback to dict)
... | aiguy mode="extract" field="field_name" prompt="what to extract"
... | aiguy mode="extract" field="email" prompt="domain" new_field_name="domain"

# Query tools
... | aiguy mode="explain"                         # what does this SPL do?
... | aiguy mode="suggest"                        # suggest a follow-up query
| makeresults | aiguy mode="dashboard" prompt="app/name" # summarize a dashboard
Behavior
BehaviorDetail
SamplingScans first 10,000 rows, picks 20 unique for the LLM. Remaining rows stream through.
BatchingEnrich mode sends values in 3,000-char batches. Connection reused across batches.
Deadline25 second total time budget. If exceeded, returns partial results with what it has.
Field safetyNever overwrites the source field. Defaults to ai_answer if no new_field_name set.
Rate limitScheduled searches skip LLM if the same alert ran within 10 minutes.
Small sets8 or fewer unique values skip regex, go straight to dict mapping (faster).
ErrorsShows diagnostics: finish_reason, response time, chars sent. Never crashes the search.
⚠ Safety
aiguy is read-only — it never executes SPL, modifies data, or writes to indexes. The only external call is HTTPS to your configured LLM endpoint. For scheduled searches, it auto-skips if the same alert ran within 10 minutes to avoid unnecessary API costs.
